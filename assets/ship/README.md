## Как получен рабочий кадр

Исходник пришёл в JPEG: прозрачность в нём не настоящая, а нарисованная клетка.
Скрипт вырезает её по палитре и связности, открывает запертые просветы
(небо под тентом, вырезы палубы) и чистит остатки клетки, отрезанные блочностью JPEG.

```bash
# из каталога проекта
python3 -m venv /tmp/venv && /tmp/venv/bin/pip install pillow numpy
/tmp/venv/bin/python key.py source/hero-vessel-raw.jpg source/hero-vessel-1x.png
cwebp -q 90 -m 6 -sharp_yuv -alpha_q 100 source/hero-vessel-1x.png -o hero-vessel.webp
```

Сам `key.py` лежит в рабочей папке сессии; алгоритм: фон = нейтральный серый
в палитре 254 / 203 → заливка от рамки → добор внутренних просветов, где есть
обе клетки → удаление светлых компонент меньше 1500 px → эрозия 1 px + размытие 0,7
по альфе (съедает ореол JPEG по контуру).

## Система координат

Вся интерактивная механика задана в координатах кадра **1995 × 825**
(массивы `SPOTS` и `ROUTES` в начале `assets/js/hero.js`).

| Объект | Узел (x, y) | Якорь подписи (cx, cy) |
|---|---|---|
| 01 Пропульсивные комплексы — гребной электродвигатель | 370, 624 | 358, 430 |
| 02 Главные двигатели — главный двигатель с генератором | 648, 610 | 668, 430 |
| 03 Системы накопления энергии — аккумуляторные стойки | 1110, 638 | 1098, 348 |
| 04 ГРЩ и электрооборудование — распределительные щиты | 1468, 650 | 1452, 348 |

`BUS = 548` — высота главной энергошины: полоса потолка машинного отделения,
где линия не наезжает ни на корпус, ни на оборудование.
Ватерлиния кадра — у нижней кромки, судно стоит на ней без обрезки.

## Замена на новый рендер

1. Пропорция **1995 : 825** (2,42 : 1), прозрачный фон, разрез по правому борту.
2. Положить как `hero-vessel.webp` (или задать `window.AB_HERO_PLATE = 'https://…'`
   до подключения `hero.js`).
3. Пересчитать `SPOTS` / `ROUTES` / `BUS`. Разметка, стили и логика не меняются.

Проверить координаты проще всего так — точки и шина рисуются поверх кадра:

```bash
ffmpeg -i hero-vessel.webp -vf "drawgrid=w=100:h=100:t=2:c=0xFF0000@0.55" -frames:v 1 -y /tmp/grid.png
```

## Требования к рендеру

| Параметр | Значение |
|---|---|
| Пропорция | 1995 : 825 |
| Разрешение | от 3990 × 1650 (текущий кадр только 1×) |
| Формат | WEBP/PNG с альфой — фон рисует CSS (небо, вода, тень под корпусом) |
| Композиция | судно целиком, нос и корма не обрезаны, разрез машинного отделения в нижней трети |
| Свет | холодный дневной снаружи, тёплый в помещениях — экран построен на светлой палитре |
