# AB Marine — первый экран

Светлый экран вокруг одного объекта — судна в разрезе. От присланной картинки взят
только сам кадр с вырезанным фоном; небо, вода, тень, энергоконтур, подписи направлений,
заголовок и цифры — живая вёрстка: масштабируется, индексируется, адаптируется.

Судно работает как интерактивная схема: по шине под палубой идут импульсы энергии,
узлы на машинах пульсируют, от каждой подписи к своей машине тянется выноска.
Прицел-сканер притягивается к ближайшему узлу, клик закрепляет карточку,
клик по CTA гонит по контуру всплеск.

## Состав

```
index.html                       dev-страница (шапка + первый экран)
assets/css/hero.css              стили
assets/js/hero.js                механика: параллакс, сканер, hotspot'ы, energy flow, CTA
assets/ship/hero-vessel.webp     кадр судна в разрезе 1995 × 825, 318 КБ (рабочий ассет)
assets/ship/source/              исходник, PNG без сжатия и скрипт вырезания фона
assets/ship/README.md            координаты, требования к рендеру, порядок замены
assets/img/                      материалы с abmarine.ru (логотип, фото каталога)
build-tilda.py                   сборка одного файла для Tilda
tilda/abmarine-hero.tilda.html   ← готовый блок для вставки
tilda/_test.html                 песочница: проверка изоляции внутри Tilda-подобной страницы
```

## Локальный запуск

```bash
python3 -m http.server 5173
```

`http://localhost:5173/` — страница, `http://localhost:5173/tilda/_test.html` — проверка Tilda-сборки.

## Вставка в Tilda

```bash
python3 build-tilda.py
```

Собирает `tilda/abmarine-hero.tilda.html`: весь CSS вложен в `#abmHero`,
keyframes и id с префиксом `abm`, JS в IIFE с защитой от повторного запуска.
Глобальные стили Tilda не затрагиваются — проверено в `tilda/_test.html`
(типографика, ссылки и `box-sizing` соседних блоков не меняются).

**Куда вставлять:** блок «T123 · HTML-код» на всю ширину, либо HTML-элемент
Zero Block, растянутый на 100 % ширины и высоты артборда.

**Три шага после вставки** (они же продублированы в шапке файла):

1. Загрузить `assets/ship/hero-plate.webp` в Tilda и заменить строку
   `ЗАМЕНИТЕ_НА_АДРЕС_КАРТИНКИ_В_TILDA` на адрес `https://static.tildacdn.com/…`
   (одно вхождение; размытая подложка вшита в CSS миниатюрой в 700 байт).
2. В `#abmHero` задать `--menu-h` (высота меню Tilda, если оно в потоке) и
   `--hdr-h` (верхний отступ; если меню «поверх» — его высота).
3. Заменить якоря `#catalog`, `#about`, `#formblock` на ID блоков Tilda (`#rec123456`).

Своя шапка в Tilda-сборку не попадает — там используется штатный блок меню.

## Контент — весь с abmarine.ru

| Что | Откуда |
|---|---|
| Меню: О компании · Каталог · Контакты | навигация текущего сайта (одностраничник, якоря `#about` / `#catalog` / `#footer`) |
| Кнопка «Оставить заявку» | она же в шапке сайта |
| Лид под заголовком | блок «Наши сильные стороны»: полный цикл от проектирования до сервиса |
| Направления в hotspot'ах | каталог сайта |
| Телефон 8 812 643-42-11, info@abmspb.ru, СПб / Кожевенная 30, Пн–Пт 9:30–18:30 | подвал сайта |
| Raleway, `#0075FF` / `#003D84` | текущая тема сайта |

**Нижний ряд.** Цифр вида «15 лет на рынке / 300 проектов» на abmarine.ru нет —
из референса они убраны. Сейчас там четыре проверяемых факта:
`6 направлений оборудования` · `Полный цикл` · `СПб, Кожевенная 30` · `Пн–Пт 9:30–18:30`.
Появятся подтверждённые цифры — меняются в `index.html`, разметка та же.
Порядок важен: на планшете видны первые три, на мобильном — первые две.

**Направлений в каталоге шесть, на судне — четыре.** Подписи теперь живой HTML,
так что ограничение не в картинке, а в самом кадре: на разрезе видны гребной
электродвигатель, главный двигатель, аккумуляторные стойки и щиты. Контейнерных
модулей и редукторного отсека в кадре нет — добавить их можно только новым рендером
(требования в `assets/ship/README.md`).

**Кнопка «О компании»** ведёт на текстовый раздел, поэтому иконка — стрелка,
а не «play». Появится ролик — в `index.html` рядом стоит комментарий, как
вернуть треугольник и подставить ссылку на видео.

## Правка контента

| Что | Где |
|---|---|
| Заголовок, лид, кнопки, цифры | `index.html` |
| Направления: название, описание, теги | массив `CHIPS` в начале `assets/js/hero.js` |
| Точки энергоузлов | массив `NODES` там же |
| Трассы энергии | массив `ROUTES` там же |

Координаты — в системе кадра `1157 × 748`, см. `assets/ship/README.md`.

## Вес

| | |
|---|---|
| Кадр судна | 318 КБ WEBP с альфой (исходный JPEG — 423 КБ без прозрачности) |
| CSS + JS | 26 + 17 КБ |
| Фон | градиент + вшитая в CSS миниатюра 1,1 КБ — отдельных файлов нет |

Итого первый экран ≈ 362 КБ, один внешний файл. Команды пересжатия — в
`assets/ship/README.md`.

## Поведение

| | |
|---|---|
| Курсор по экрану | судно ведёт параллакс, своё курсор-кольцо растёт над кликабельным |
| Курсор на судне | сканер-линза идёт за курсором и притягивается к ближайшей машине |
| Курсор вне судна | сканер дрейфует сам |
| Наведение на подпись | карточка направления, подсветка выноски, узла и «горячая» трасса |
| Клик по подписи | карточка закрепляется: курсор свободен, соседние наведения её не сбивают. Снять — повторный клик, клик мимо или Esc |
| Наведение на CTA | энергоконтур подзаряжается — импульсы ускоряются |
| Клик по CTA | вспышка контура, сетка сканера на весь кадр, трассы вспыхивают белым |
| Клавиатура | Tab по направлениям открывает карточки, Esc закрывает и снимает закрепление |
| Планшет | судно крупнее и уходит в нижнюю полосу, направления — живым рядом под кнопками |
| Мобильный | кадр перекадрован на машинное отделение, направления тем же рядом чипов |
| `prefers-reduced-motion` | параллакс, дрейф и импульсы выключаются |
